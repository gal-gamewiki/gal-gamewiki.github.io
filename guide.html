Galgame 新手入门指南

一、Galgame 的基本构成

  • 文本：故事的核心，以对话和旁白推进剧情。
  • 立绘：角色的半身/全身图像，会随情绪切换表情与姿势。
  • CG：关键剧情中的一枚枚精美插画，通关后可在“CG 鉴赏”中回顾。
  • 背景与音乐：营造场景氛围，BGM 与主题曲往往是玩家最深的记忆。
  • 配音：大部分商业作品为女性角色提供全程语音，男主角通常不配音。
  • 选项：在关键节点出现的选择支，决定好感度与路线走向。

三、在哪里玩 Galgame？

PC（Windows）

Galgame 最主要的平台，绝大部分作品首发于 PC。Steam、DLsite、DMM GAMES 等平台均有大量正版作品，近年许多作品同步推出官方简体/繁体中文。

Nintendo Switch / PlayStation

大量经典作品推出了全年龄移植版，如《命运石之门》《Summer Pockets》《CLANNAD》等，适合在沙发上或通勤途中游玩。

手机（Android / iOS）

部分作品有官方手机版；此外 Ren'Py、Kirikiri（吉里吉里）等引擎也有移动端模拟器可以运行部分 PC 作品。

四、常见游戏引擎

  • KiriKiri（吉里吉里）：日本商业 galgame 最常用的引擎之一，柚子社等品牌长期使用。
  • Ren'Py：基于 Python 的开源引擎，欧美独立视觉小说的主流选择（如《心跳文学部》）。
  • NScripter / ONScripter：早期同人作品常用，《寒蝉鸣泣之时》原版即基于 NScripter。
  • Artemis、Unity 等：近年越来越多作品采用的现代引擎，支持更丰富的演出效果。

五、常见问题与技巧

日文游戏乱码 / 无法启动？

部分老牌日文 PC 游戏要求系统区域为日语。可在 Windows“区域设置 → 非 Unicode 程序的语言”中改为日语，或使用 Locale Emulator 等转区工具运行。

如何高效回收全部路线？

  1. 在每个选项前单独存档，并给存档命名。
  2. 开启“仅快进已读文本”，避免错过新内容。
  3. 先自由游玩一遍，再参照攻略补全剩余结局与 CG。

避免剧透的小建议

悬疑、叙诡类作品（如《Ever17》《命运石之门》《寒蝉》）一旦被剧透体验会大打折扣，建议通关前少看评论区和相关视频。

六、给新手的入坑路线

轻松起步：《ATRI》→《千恋＊万花》→《Summer Pockets》

剧情进阶：《命运石之门》→《CLANNAD》→《Fate/stay night》

高阶挑战：《Muv-Luv》三部曲 →《WHITE ALBUM 2》→《樱之诗》
